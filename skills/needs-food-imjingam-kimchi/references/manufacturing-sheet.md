# 임진감김치 제조 작업서 틀

빈 값은 `미제공`, 미측정 값은 `미측정`으로 표시한다. 아래 단계는 표준서 대조용 후보이며 제품에 적용되는 승인 공정과 순서로 수정한다.

## 작업 식별

제품명 / 제품 유형 / 제조 LOT / 생산일 / 목표량·중량 기준 / 배합표 버전 / 제조표준서 버전 / 담당자 / 작성 상태

## 원료 소요량

| 원료·규격 | 원료 LOT | 기준량·단위 | 환산량·단위 | 사용가능 재고 | 부족량 | 근거 |
|---|---|---|---|---|---|---|

계산식, 수율의 적용 단계, 반올림 방법과 배합 합계를 기록한다. 포장재는 포장 규격과 목표 포장 수가 있을 때 별도로 계산한다.

## 공정별 기록

| 단계 후보 | 작업 내용 | 승인 기준·출처 | 실측·시각 | 담당자 | 판정·조치 |
|---|---|---|---|---|---|
| 입고·선별 | 원료 규격·LOT·수량 확인 | | | | |
| 전처리 | 제품별 손질·세척 작업 | | | | |
| 절임 | 적용 여부와 조건 확인 | | | | |
| 세척·탈수 | 중간재 중량과 수율 기록 | | | | |
| 양념 준비 | 원료별 계량과 배합 버전 확인 | | | | |
| 혼합·충전 | 실제 투입량·완제품량 기록 | | | | |
| 포장 | 포장 LOT·중량·표시 확인 | | | | |
| 보관·출고 | 적용 조건·검사 결과·출고 상태 확인 | | | | |

발효·숙성 단계의 유무와 위치는 해당 표준서에 따른다. 특정 단계를 임의로 중요관리점(CCP)으로 지정하지 않는다.

## 품질·추적

| 검사 항목 | 시료·제조 LOT | 내부/외부 | 적용 기준·출처 | 결과·단위 | 검사시각 | 판정 |
|---|---|---|---|---|---|---|

마지막에 원료 LOT → 제조 LOT → 포장 LOT → 출고처 연결의 누락 여부, 기준 대비 편차, 확인 담당자와 승인 상태를 정리한다.
