# 니즈푸드 대화 중심 화면

2026-10-03. React V2 기존 화면의 표시 순서와 모바일 음성 시작을 정리했다.

- 데스크톱 왼쪽에는 최근 질문과 생산·품질/문서·규칙 질문 예시, 오른쪽에는 지식베이스와 데이터허브를 배치했다. 중앙에는 배치 문맥, 대화, 입력창과 음성 시작을 유지했다.
- 모바일에서는 질문 목록과 자료 목록을 각 버튼으로 여닫는다. 대화창과 실시간 음성 시작 버튼은 바로 보인다.
- 업무 선택용 탭을 제거하고 질문 예시를 한곳에 모았다. 답변 근거 열기, 문서 검색과 DB 조회는 유지했다.
- 로컬에서 서버 키를 사용하면 브라우저 AI 접근 코드 없이 WebRTC 세션·도구 조회를 호출하도록 수정했다. 로컬 아닌 접속은 관리자 접근 코드를 유지한다.
- 문자·음성 API가 반환하는 크레딧 소진, 일반 사용량 제한, 키 인증 오류를 구분해 안내한다.

검증:
- TypeScript/Vite 프로덕션 빌드 통과.
- 변경된 API 테스트 6개 통과: 키/크레딧 안내, 재시도 후 동시 슬롯 해제, 코드 없는 로컬 음성 세션, 음성 크레딧 오류.
- 실제 페이지 데스크톱·390px 전환과 모바일 질문·자료 패널, 데이터허브 목록을 확인했다.
- 음성 시작 버튼은 제공되며 브라우저에서 권한 요청 상태로 진입했다. 현재 OpenAI 키는 `credit_balance_exhausted`를 반환한다. 따라서 실시간 음성 대화의 실제 음성 송수신은 크레딧이 보충된 뒤 확인할 수 있다.
- API 키는 루트 `.env`에 권한 0600으로 저장했다. 파일은 Git에서 무시된다.
