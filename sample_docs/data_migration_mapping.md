# PC Excel 10년 데이터 이관 예시

| 기존 Excel | TO-BE 영역 | 핵심 키 | 품질 점검 |
|---|---|---|---|
| 메뉴·식단 | 메뉴 마스터 | 메뉴코드·적용일 | 중복명·유효기간 |
| 레시피·조리법 | 레시피·BOM | 메뉴코드·개정번호 | 단위·투입순서 |
| 검식 규칙 | 품질계획 | 메뉴·배치·검사항목 | 표본수·승인자 |
| 재고 | 원료재고 | 원료코드·입고일 | 음수·단위·유통기한 |
| 원가 | 재료원가 | 원료코드·기준일 | 통화·단가 유효기간 |

이관 순서는 데이터 프로파일링, 코드 표준화, 중복 제거, 단위 변환, 샘플 검증, 전체 적재, 사용자 검수 순으로 진행한다.
