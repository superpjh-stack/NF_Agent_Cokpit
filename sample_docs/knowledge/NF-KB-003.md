# 레시피 개정과 승인

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

레시피 개정 사유, 변경 전후, 대상 메뉴와 적용 시점을 기록한다. 승인된 버전이 확인되지 않으면 현행 버전을 임의 교체하지 않는다. 승인 여부는 담당자 기록으로 확인한다.
