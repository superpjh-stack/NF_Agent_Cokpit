# 출하 상태와 납기 대응

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

출하 계획 질문에는 `shipments`의 계획수량과 실제 출하수량을 날짜별·메뉴별로 대조한다. 이 급식 데이터의 수량 단위는 kg가 아니라 식수(식)다. 총계는 계획 합계, 실제 출하 합계, 미출하 차이(계획-실적)로 표시하고, 메뉴별 납기와 상태를 함께 제시한다. 실제 출하량이 0이면 임의로 출하 완료로 해석하지 않는다.

조회일의 기록이 없으면 최신 기록의 날짜를 분명히 밝히고 오늘 실적처럼 표현하지 않는다. 이 데모 DB는 실제 운영 기록이 아닌 예시다. 지연 배치와 출하 대기는 관련 기록을 연결해 담당자에게 확인할 조치로 제안한다. 에이전트는 출하 승인이나 생산중지를 실행하지 않는다.
