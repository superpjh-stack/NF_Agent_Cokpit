# 출하 상태와 납기 대응

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

출하 계획량·실적·납기와 품질 확인 상태를 대조한다. 지연 배치와 출하 대기는 관련 기록을 연결해 담당자에게 확인할 조치로 제안한다. 에이전트는 출하 승인이나 생산중지를 실행하지 않는다.
