# 원료 부족과 대체 검토

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

재고가 안전재고 미만이면 부족 경고를 표시하고 생산 소요량과 발주 상태를 확인한다. 안전재고 부족과 생산 소요량 부족은 별개다. 대체 원료는 알레르기 표시와 레시피 영향 검토 및 담당자 승인 후 적용한다.
