# 데이터 이관과 근거 사용

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

SQLite는 오프라인 시제품용이다. PostgreSQL 이관 시 업무 테이블·지식문서·규칙·설정을 함께 옮기고 원본 행 수를 검증한다. 이 폴더의 문서와 규칙은 미승인 예시이며 실제 운영 기준이 아니다. 실제 승인 문서와 충돌하면 예시를 기준으로 판정하지 않는다.
