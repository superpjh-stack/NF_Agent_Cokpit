# 배합표와 원료 소요량

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

승인 배합표의 버전과 중량 기준을 먼저 확인한다. 같은 기준에서 목표량/기준량으로 환산한다. 현재 qty_per_meal은 1식 기준 사용량이며 김치 완제품 kg 기준 배합이 아니다. 수율과 단위가 없으면 확정 계산하지 않는다.

DB 연결: recipe_costs / M001,M002
