# 배치 조리조건과 편차

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

배치 ID로 온도·교반속도·압력·모터속도와 측정 시각을 연결한다. 승인 목표값이 없으면 측정값만 보고하고 기준 초과 여부는 미확인으로 표시한다. 솥 조리값을 김치 절임·발효 기준으로 사용하지 않는다.
