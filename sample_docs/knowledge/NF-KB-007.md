# 내부 검식과 외부기관 검사

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

영양사 관능 검식과 외부기관 검사는 구분한다. 검식 주의가 있으면 해당 표본과 LOT, 적용 기준, 후속 검사를 확인한다. 의뢰중 또는 미측정은 합격이 아니다. 표본의 적합 결과로 전체 생산분의 품질을 보증하지 않는다.
