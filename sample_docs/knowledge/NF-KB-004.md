# 원료 입고와 재고 확인

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

원료 규격, 수량, 단위, 사용기한과 입고검사 결과를 확인한다. 데모 재고에는 LOT별 예약량과 보류량이 없어 사용가능 재고를 확정할 수 없다. 사용기한과 재고 갱신 시각을 함께 제시한다.

DB 연결: inventory / R001,R002
