# 임진감김치 제조 기준 준비

> 시제품 검증용 예시. 실제 승인 표준이 아닙니다.

임진감김치의 실제 제품 유형과 승인 배합표·제조표준서·품질기준은 현재 제공되지 않았다. 목표 생산량이 원물, 절임·탈수 후, 완제품 중 어느 기준인지 확인한다. 입고·전처리·절임·세척·탈수·양념·혼합·포장·보관은 표준서 대조용 후보이며 순서와 적용 여부는 미확인이다. 배합비, 시간, 온도, 염도, pH, 소비기한은 임의 확정하지 않는다. 작업서는 제조 검토용 초안으로 작성한다.
