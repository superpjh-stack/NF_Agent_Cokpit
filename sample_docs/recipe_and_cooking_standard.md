# 니즈푸드 레시피·조리 기준 예시

> 시제품 검증용 가상 문서입니다. 운영 적용 전 승인된 실제 레시피로 교체해야 합니다.

## 소고기미역국 세트

- 배치별 작업지시에서 메뉴코드, 계획 식수, 솥 번호를 확인한다.
- 작업자는 설비 앞 화면에서 레시피와 투입 순서를 확인한다.
- 조리 중 온도, 교반속도, 압력, 모터속도를 배치 ID와 함께 저장한다.
- 조리 종료 후 실제 생산량과 종료시각을 등록한다.

## 예외 처리

- 목표 온도 도달이 지연되면 해당 솥의 설비상태와 재료 투입시각을 확인한다.
- 레시피 변경은 영양사와 생산책임자의 승인을 받은 뒤 개정이력을 남긴다.
