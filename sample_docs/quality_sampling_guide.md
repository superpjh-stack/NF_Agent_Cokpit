# 니즈푸드 검식·샘플링 운영 예시

> 시제품 검증용 문서이며 법정 또는 사내 승인 기준을 대체하지 않습니다.

- 내부 영양사 검식은 샘플링 결과로 기록하며 검사한 배치와 검사하지 않은 배치를 구분한다.
- 기존 예시 관행인 10솥 중 1솥 검식은 현행 기준으로 기록하되, 최종 샘플링 규칙은 품질책임자의 승인을 받아 시스템에 등록한다.
- 맛, 향, 색, 염도 체감과 특이사항을 구조화해 입력한다.
- 외부기관 검사는 의뢰일, 시료 수, 기관명, 검사상태와 최종 결과를 별도 관리한다.
- 주의 또는 부적합 발생 시 관련 배치, 조리조건, 출하상태를 함께 확인한다.
